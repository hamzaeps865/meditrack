# Premium UI Redesign — Complete Plan (Updated with Cards + Icons)

## Design Philosophy (research-based)
Based on [2026 Healthcare Dashboard Best Practices](https://fuselabcreative.com/healthcare-dashboard-design-best-practices/) and [SaaS Dashboard Trends 2025](https://www.linkedin.com/pulse/how-apply-20252026-design-trends-dashboards-saas-products-zirva-zahid-sbyvf):

- **Soft premium flat**: 8px rounded corners, multi-layer soft shadows, no skeuomorphism
- **Glassmorphism-lite**: subtle frosted backgrounds on overlays/modals
- **Icon-led KPI cards**: every stat card has a premium medical icon in a colored circle
- **Micro-interactions**: hover elevation, active accent bars, smooth transitions
- **Mobile-first responsive**: hamburger sidebar drawer, stacking grids, scrollable tables

---

## R3 — Premium KPI Stat Cards (all dashboards)

**This is the key "premium" upgrade.** Every stat card gets:

```
┌─────────────────────────────────┐
│ ┌─────┐                         │
│ │ 📊  │  Total Patients         │
│ │icon │  ─────────────────       │
│ └─────┘                         │
│  1,247                          │
│  ↑ 12% from last month          │
└─────────────────────────────────┘
```

- Premium icon in colored circle (emerald-50 bg, emerald-700 icon)
- Large bold number (text-3xl font-bold)
- Small caption/trend below
- `shadow-card` base, `hover:shadow-hover` on interactive
- 8px rounded corners
- Applied to: admin dashboard (4 cards), doctor dashboard (3 cards), receptionist (4 cards), nurse (3 cards), lab (4 cards), pharmacist (3 cards)

## R5 — Premium Icons (`@phosphor-icons/react`)

**Install Phosphor Icons** — 9,072 icons, 6 weight variants (Thin/Light/Regular/Bold/Fill/Duotone), MIT free.

Medical-specific icons available:
- `Stethoscope`, `Heartbeat`, `Pill`, `Thermometer`, `Syringe`, `Clipboard_pulse`, `Hospital`, `User_nurse`, `Test_tube`, `Microscope`, `Dna`, `Brain`, `Tooth`, `Eye`, `Bone`, `Lungs`, `First_aid_kit`, `Ambulance`, `Wheelchair`, `Bandage`

Replace lucide icons on KEY visible surfaces:
- Sidebar nav items → Phosphor Duotone (premium duotone style)
- Stat card icons → Phosphor Duotone in colored circles
- Dashboard section headers → Phosphor icons

Keep lucide-react for secondary/inline icons (X, Plus, Loader, etc.) — no need to replace everything.

## R6 — Responsive Tables

All `<table>` elements wrapped in:
```tsx
<div className="overflow-x-auto">
  <table className="w-full min-w-[600px]">
```
Horizontal scroll on mobile, full table on desktop.

Affected: admin appointments, billing, users, pharmacy inventory, doctor analytics, audit logs.

## R7 — Responsive Action Bars

All `flex items-center justify-between` action rows → `flex flex-col sm:flex-row gap-3`
Buttons stack vertically on mobile.
