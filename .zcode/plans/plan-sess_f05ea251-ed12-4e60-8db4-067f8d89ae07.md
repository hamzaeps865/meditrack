# Pakistan Independence Day Color Scheme — Full Rebrand

## Pakistan Flag Colors
- **Primary Green:** `#01411C` (flag green) — main brand color
- **Lighter Green:** `#0a5c3a` — for gradients, hovers, accents
- **White:** `#FFFFFF` — cards, backgrounds (with slight green-tinted off-white for pages)
- **Crescent Gold accent:** `#c5a55a` — optional for special highlights (sidebar logo)

## Changes (3 layers):

### Layer 1: CSS Variables (`globals.css`) — the core rebrand
Replace all navy-blue tokens with Pakistan green:
- `--primary: #01411C` (was `#1E3A5F`)
- `--ring`, `--sidebar-primary`, `--sidebar-accent-foreground`, `--sidebar-ring` — all → `#01411C`
- `--accent: #0a5c3a` (lighter green, was teal `#0F9B8E`)
- Dark mode primary → lighter green `#0a7a4f`
- Update the doc-comment palette block

### Layer 2: Hardcoded hex colors — find & replace across ~25 files
- All `#1E3A5F` → `#01411C` (49 occurrences across the codebase)
- All `#2d6a9f` → `#0a5c3a` (11 occurrences — gradient pairs)
- All `linear-gradient(135deg, #1E3A5F, #2d6a9f)` → `linear-gradient(135deg, #01411C, #0a5c3a)`
- All `#f5f7fa` → `#f0f7f3` (48 occurrences — subtle green-tinted page background)
- `#dbe4ee` and `#eef1f5` → green-tinted equivalents
- `#2d5280` → `#0a5c3a`

### Layer 3: Favicon (`icon.tsx`)
- Replace `#1E3A5F` background → `#01411C`

### What stays the same:
- Status semantic colors (red for danger, amber for pending, emerald for success, blue for info) — these are universal and shouldn't change
- The white crescent moon look on the sidebar logo via the existing ShieldCheck icon
- Card backgrounds stay white
- Text contrast maintained (green is dark enough for white text on primary)
