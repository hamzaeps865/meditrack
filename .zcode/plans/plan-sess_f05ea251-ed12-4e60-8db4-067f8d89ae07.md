# Lab Test Workflow — Lab Technician Role + Portal + Automated Notifications

## Decisions confirmed
- **Full lab technician role** with their own `/lab` portal (like pharmacist has `/pharmacy`)
- **Both manual + predefined tests** — lab tech can type results free-text OR select from predefined templates with reference ranges

---

## How the flow works end-to-end:

```
1. DOCTOR orders "CBC" during a visit
   → Lab order created with status: 'ordered'

2. Lab order AUTO-APPEARS in the LAB TECHNICIAN's queue
   → Lab tech sees: patient name, test name, doctor, priority, ordered time

3. LAB TECH processes it:
   → Click "Collect Sample" → status: 'sample_collected'
   → Enter results (free-text OR from predefined template) → status: 'completed'

4. SYSTEM AUTO-NOTIFIES:
   → PATIENT gets bell notification: "Lab result ready — CBC"
   → DOCTOR gets bell notification: "Lab result available for [patient] — CBC"

5. PATIENT sees result on /patient/lab-results
   DOCTOR sees result on the visit detail page
```

## L2 — Schema Changes

**Modified `lab-orders.ts`:**
- Add to status enum: `'sample_collected'`, `'in_progress'` (between `ordered` and `completed`)
- Add columns: `performedBy` (uuid FK→users), `collectedAt` (timestamp), `result` (already exists but rename usage to support structured), `priority` (varchar: routine/urgent/stat)

**New `lab_test_catalog.ts`:**
- `lab_tests` table: `id`, `name` (e.g. "Complete Blood Count"), `shortName` (e.g. "CBC"), `category` (Hematology/Biochemistry/Microbiology/Serology), `referenceRange` (text, e.g. "Hb: 13-17 g/dL, WBC: 4-11 ×10⁹/L"), `units` (varchar), `sampleType` (Blood/Urine/Stool/Sputum)

**Seed script:** ~30 common lab tests (CBC, Blood Sugar R, LFTs, Lipid Profile, Urine R/E, Dengue NS1, Blood Group, HBsAg, TFT, etc.)

---

## L3 — Lab Actions (`lab-actions.ts`)

- `getLabQueue()` — lab-facing: all ordered + sample_collected tests, sorted by priority + wait time
- `collectSample(labOrderId)` — sets status to `sample_collected`, records `collectedAt`
- `submitLabResult(labOrderId, result, notes?)` — sets status to `completed`, stores result text + `performedBy` + `completedAt`. Auto-notifies patient + doctor.
- `getCompletedLabOrders(limit)` — lab-facing history of completed tests
- `getLabOrdersForDoctor(doctorId)` — doctor-facing: all lab orders for their patients with results
- `searchLabCatalog(query)` — autocomplete for doctor when ordering tests
- `getAllLabTests()` — admin: manage the test catalog

## L4 — Lab Technician Portal

**New route `/lab` — Lab Queue dashboard:**
- Stat cards: pending tests, collected samples awaiting results, completed today, urgent/stat tests
- Queue table: patient name, test name, doctor, priority badge (Stat=red, Urgent=orange, Routine=blue), ordered time, status
- Per-row actions: "Collect Sample" button, "Enter Result" button

**New route `/lab/completed` — Completed history:**
- List of all completed tests with patient, result, time

**New route `/lab/settings` — Settings:**
- Edit name, change password (reuse nurse settings pattern)

**Result entry form:**
- Shows test name + patient info
- If the test is in the catalog: shows reference range + sample type + a structured text area pre-filled with the template (e.g. "Hb: ___ g/dL (13-17), WBC: ___ ×10⁹/L (4-11)")
- If the test is manual: free-text area for typing the result
- Optional notes field

## L5 — Doctor Integration

**Visit form changes:**
- When ordering lab tests, the doctor gets autocomplete from the `lab_tests` catalog (like the medicine autocomplete) — type "CBC" → shows "Complete Blood Count (Hematology)" with reference range
- Manual typing still works for tests not in the catalog

**Visit detail page changes:**
- After the visit is completed, the doctor's appointment detail page shows a **Lab Results card** with each test, its status, and results when available

---

## L6 — Notifications

**New `'lab'` notification type** added to the system:
- **Patient bell:** "Lab Result Ready — [test name]. View your results." → links to `/patient/lab-results`
- **Doctor bell:** "Lab Result Available — [patient name], [test name]" → links to the appointment detail

**Implementation:** In `submitLabResult`, after saving, resolve the patient (via visit→patient→email) and doctor, then they'll see notifications on their next page load (computed in `getNotifications()`).
